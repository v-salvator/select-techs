# select-techs

My personal, curated list of repos, tools, and tech stacks: what I use now, what I've tried, and what I'm keeping an eye on. Each entry says why it's here, not just where to find it.

## Categories

| Category | What goes here |
| --- | --- |
| [Front-end](frontend.md) | UI frameworks, component libraries, styling, build tools |
| [Back-end](backend.md) | Servers, APIs, databases, auth, queues |
| [DevOps](devops.md) | CI/CD, hosting, containers, infra, monitoring |
| [Code review](code-review.md) | Review tools, linters, static analysis, AI reviewers |
| [Video editing](video-editing.md) | Editors, motion graphics, programmatic video, launch films |
| [Image generation](image-generation.md) | Image models, prompting tools, design assets |
| [3D rendering](3d-rendering.md) | 3D engines, WebGL, modeling, rendering pipelines |

## Status legend

| Status | Meaning |
| --- | --- |
| 🟢 `using` | Part of my current stack |
| 🟡 `tried` | Used it, have an opinion |
| 🔵 `watching` | Looks promising, haven't used it yet |
| ⚫ `dropped` | Used it and moved on (note why) |
