### [claude-trading-skills](https://github.com/tradermonty/claude-trading-skills)
`status: watching` · `tags: agent-skill, claude-code, trading, risk, journaling, workflow` · added 2026-11

A Claude Skills toolkit by TraderMonty for equity investors and traders: market analysis, charting, screeners, risk checks, trade planning, and journaling. The official README says the goal is not to outsource buy/sell decisions to AI, but to structure market review, risk management, trade planning, journaling, and continuous improvement.
**Why I care:** The standout is the risk-discipline layer — pre-trade checks, drawdown stops, position sizing, and a trade journal — rather than another stock picker.
**Notes:** MIT (Copyright 2026 TraderMonty), confirmed in the repo `LICENSE`. 74 skills under `skills/` (still the count as of 2026-11-23). The earlier note recorded 3,811 stars as of 2026-11; GitHub showed about 7,876 stars as of 2026-11-23 (Asia/Taipei). Highlighted skills confirmed in the repo: `pre-trade-discipline-gate`, `drawdown-circuit-breaker`, `position-sizer`, `trader-memory-core`. The README says the project is not financial advice or a signal service, is "not a promise of profitability," is "not designed for fully automated trading," and is "a research, journaling, and risk-review assistant, **not** an automated trading system" that "does **not** place orders." Discovered via [工程師阿穆 | Build with AI (@homuchen.build.ai)](https://www.threads.com/@homuchen.build.ai/post/Dfo5Qmmk8tG); the post cited 3,663 stars. [Author continuation](https://www.threads.com/@homuchen.build.ai/post/Dfo5RnDky1M) says the data sources are US-stock only (not independently verified as a hard repo-wide limit). His [writeup](https://homuchen.com/posts/claude-stock-skill-tradermonty-taiwan/) describes adapting `market-breadth-analyzer` for Taiwan stocks with FinMind, published as [HoMuChen/tw-market-breadth-skill](https://github.com/HoMuChen/tw-market-breadth-skill). Also shared by [AI郵報 (@aiposthub)](https://www.threads.com/@aiposthub/post/DgFGcZ2ARsd) (no stills; the post itself has no GitHub URL). Its article <https://www.aiposthub.com/tradermonty-claude-trading-skills-guide/> identifies tradermonty/claude-trading-skills and cites 7,850 stars. The post lists five capabilities — market analysis, stock screening, position sizing, risk management, and trade review — plus a "15-minute daily market check," and says you can start without a paid market-data API by uploading Skills in Claude's web app. The README's recommended starting path uses the same "15-minute daily market check" label for the `market-regime-daily` workflow, alongside four other operational workflows; that is a different grouping than the post's five capabilities. The README's "No API Key Starter Path" (five skills) says it works with public CSVs, chart screenshots, and local files and "does not require a paid market-data API subscription," while also noting that "no API" still needs that external data and that some other skills and workflows require FMP, FINVIZ Elite, or Alpaca. The "Use with Claude Web App" section describes downloading a `.skill` ZIP and uploading it under Customize > Skills. Docs: <https://tradermonty.github.io/claude-trading-skills/>. Not tested.
