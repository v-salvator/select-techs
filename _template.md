# Entry template

Copy this block into a category file.

```markdown
### [Name](https://link-to-repo-or-site)
`status: watching` · `tags: tag-one, tag-two` · added YYYY-MM

One line on what it is.
**Why I care:** What problem it solves for me, or why it caught my eye.
**Notes:** How I've used it, gotchas, alternatives I compared it with.
```

- **status:** `using` · `tried` · `watching` · `dropped` (see the legend in the [README](README.md))
- **tags:** short lowercase keywords so the file is easy to search
- **added:** when you added the entry, so you know how old the note is
- For `dropped`, say why you moved on and what you use instead.
